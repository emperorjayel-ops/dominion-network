Virtual Theater — watch together Demo

The heart of the virtual world: members come into a virtual theater and watch movies together — they see each other, hear each other, and talk and comment together while the movie plays, like being in the same room on the same night.

  • The movie

    Streams from the library bases — PeerTube / Jellyfin — with synchronized watch-together playback, so every seat in the theater is on the same moment of the film.

  • The room

    The Jitsi Meet / WebRTC layer carries live voice, video, and comments in the room — faces in the seats, voices between the scenes, comments while it plays.

  • Demo honesty

    No theater is live in this demo: no film streams, no room connects, and no one else is in the seats. The open-source foundations are pulled and credited in the Open Source Code section; the live theater opens when the real integrations connect.

Gaming — play together Demo

Game nights in the same virtual world: members play video games together — streamed play through Sunshine + Moonlight, and classic play-together sessions through RetroArch netplay, with the room's voice and chat running alongside the game. The platform also plugs into PlayStation and into Xbox so console members join the same rooms — both connections are Coming Soon: they run through each console maker's official developer program, shown as plug-in panels in the Open Source Code section. No developer account is enrolled or approved yet, and nothing is connected.

As directed by Jay: all the open-source code dealing with media and multimedia, and all the open-source code dealing with telecommunications, pulled into one place for Dominion Network — the same pattern used on the other apps, where FinSwap links the open-source Bitcoin Core + Counterparty code and credits it in-app. In Jay's framing, this is “a whole virtual world for media” — one world where members watch together in a virtual theater, talk face to face, message, call, and move large files of any kind. Media & Multimedia — open-source bases Credited

The streaming side of Dominion Network — the books, movies, music, and live programming in the shelves above — stands on these open-source media projects:

  • PeerTube AGPL-3.0

    Decentralized, federated video platform. Dominion's base for hosted video and movie channels that no single company controls — videos can federate across independent servers while staying watchable in one app.

  • Jellyfin GPL-2.0

    Free software media server for streaming movies, shows, and music to apps on every screen. Dominion's base for the streaming library shelves — the books, movies, and music library server behind the demo placeholders above.

  • Owncast MIT

    Self-hosted live video streaming and chat server. Dominion's base for live broadcasts — live programs, live teaching, and live community events with chat alongside the stream.

Supporting open-source media tooling in the same pull: FFmpeg (LGPL/GPL — the transcoding engine that prepares video and audio for every screen) and Video.js (Apache-2.0 — the open web video player). Credited here with the three platform bases above.

Telecommunications — open-source bases VoIP first

The telecom side of Dominion Network starts with Voice over IP calling — VoIP calling is the first telecom feature to stand up. Its open-source bases:

  • WebRTC BSD-3-Clause

    The open real-time communication engine built into every modern browser — carries live voice and video directly between devices. The foundation under Dominion's in-app calling and the local camera preview demoed above.

  • Jitsi Meet Apache-2.0

    Open-source video conferencing and calling, built on WebRTC. Dominion's base for group voice and video calls and meeting rooms.

  • Linphone GPL / dual-licensed

    Open-source VoIP phone (SIP) for voice and video calls on phones and desktops. Dominion's base for a dialer-style calling app experience — a real phone call feel over the internet.

  • Asterisk GPL-2.0

    The open-source PBX and telephony engine — the switchboard that routes calls, voicemail, and conference rooms. Dominion's base for the phone-system side of VoIP calling.

  • FreeSWITCH MPL-1.1

    Open-source telephony platform built for large-scale voice, video, and messaging routing. Stands alongside Asterisk as a switching base for Dominion calling at network scale.

Demo honesty: no VoIP provider, phone number, or calling plan is connected yet, so no real call can be placed from this page. These five projects are pulled and credited as the code foundation — the live calling service stands up when a real provider and integration connect.

Talking & Messaging — open-source bases Credited

How members talk inside the virtual world — face to face, out loud, on screen, and in writing:

  • Jitsi Meet + WebRTC Apache-2.0 · BSD-3-Clause

    Video chat, voice chat, and screen sharing. Jitsi Meet rooms run on the WebRTC engine — members see and hear each other and share their screens, right in the app. These are the same bases credited in the VoIP card above; here they carry the face-to-face layer of the whole world.

  • BigBlueButton LGPL-3.0

    Open-source virtual classroom and group-room platform — multi-person video, voice, screen sharing, and shared boards in one room. Dominion's base for larger group rooms, classes, and teaching sessions.

  • Matrix — with the Element client Apache-2.0

    Open, decentralized protocol for texting and messaging — encrypted chats and rooms that federate across independent servers, with Element as the reference app. Dominion's base for member messaging beyond this demo's session-only chat rooms.

  • XMPP Open standard

    The long-running open standard for instant messaging and presence — the original federated chat protocol. Stands alongside Matrix as a messaging base, so Dominion chat is built on open standards, not one company's closed system.

Large Files — moving any content Credited

Jay specifically asked for the open-source code to be able to move large files — videos, music, any type of content. These are the bases that carry big files across the network:

  • IPFS MIT / Apache-2.0

    Peer-to-peer, content-addressed file network — a large video or music file is fetched from whoever holds it, verified by its content fingerprint, not by trusting one server. Dominion's base for distributing big media files across the network.

  • WebTorrent MIT

    Streaming torrent technology that runs in the browser — the same peer-to-peer swarm idea as BitTorrent, playable while it downloads. Dominion's base for streaming large videos and music directly between members' devices.

  • Syncthing MPL-2.0

    Open-source continuous file synchronization — folders stay in sync between a member's own devices, directly and encrypted, with no central cloud holding the files. Dominion's base for keeping a member's library with them on every screen.

  • Nextcloud AGPL-3.0

    Self-hosted file sharing and collaboration platform — large-file upload, sharing links, and group folders under the network's own roof. Dominion's base for member file sharing and shared media folders.

Together: IPFS and WebTorrent move large files peer-to-peer, Syncthing keeps them synced across a member's devices, and Nextcloud gives members a sharing home for them — videos, music, and any other content, without file size being the wall.

Gaming — play together Credited

Members play video games together on the platform — game nights inside the same virtual world as the theater and the chat rooms. The open-source gaming bases:

  • Sunshine GPL-3.0

    Open-source game streaming host — it runs the game on a host machine and streams the picture and sound out to players, with their controllers talking back in real time.

  • Moonlight GPL-3.0

    Open-source game streaming client — the player-side half of the pair. Members open Moonlight on a phone, tablet, TV, or computer and play the streamed game from wherever they are. Sunshine + Moonlight together are Dominion's foundation for streamed play-together sessions.

  • RetroArch GPL-3.0

    Open-source front-end for game engines (cores), with built-in netplay — classic games played together online, each member's copy kept in sync. Dominion's base for retro play-together sessions inside the virtual world. Members play games they own; no game library or ROMs are provided by this demo.

Shared with HIIYAH — eSIM foundation Same foundation

Dominion Network's telecom side shares the same open-source eSIM foundation Jay is building HIIYAH on:

  • OpenEUICC / EasyEUICC

    Open-source eUICC management — the code that works with removable and embedded eSIM chips so profiles can be managed outside a carrier's own app.

  • lpac LGPL-2.1

    Open-source local profile assistant (LPA) — the code that downloads, installs, and switches eSIM profiles on a device.

HIIYAH itself is the next build after Dominion Network — it is not built in this app. What is reflected here is the shared foundation only: the same eSIM open-source code base, credited the same way, so Dominion's telecom side and HIIYAH stand on one foundation.

Private Install — No Store Needed

Honest guide

How people in Jay's network can put Dominion Network on their phone like any other app icon, without the Play Store or the Apple Store — stated honestly, with what is and is not possible today.

Android — Add to Home Screen

This works today for a web app like this demo, with no store involved:

  1. Open the app's shared link in Chrome on the Android phone.
  2. Tap the ⋮ menu in the top-right of Chrome.
  3. Tap “Add to Home screen” (or “Install app” if Chrome offers it).
  4. Confirm the name — the Dominion Network icon now sits on the home screen and opens full-screen, like a store app.
About an APK: sideloading a private APK is only possible if a signed APK is built and hosted first. That step is still needed — no APK exists yet, and this page does not offer one for download.

iPhone — Add to Home Screen

This works today for a web app like this demo, with no store involved:

  1. Open the app's shared link in Safari on the iPhone.
  2. Tap the Share button (the square with an arrow).
  3. Tap “Add to Home Screen.”
  4. Confirm the name — the Dominion Network icon now sits on the home screen and opens full-screen, like a store app.
About native iPhone apps: Apple does not allow private native app distribution outside the App Store / TestFlight at scale. The honest private routes are the web-app home-screen install above, or a TestFlight invite for a native build — and no native build or TestFlight invite exists yet. There is no jailbreak workaround offered here.
